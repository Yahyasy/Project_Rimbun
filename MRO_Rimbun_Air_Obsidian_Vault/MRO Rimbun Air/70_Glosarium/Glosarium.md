# Glosarium

Istilah yang dipakai di dokumen dan sistem MRO Rimbun Air. Kolom **Di sistem** menunjuk modul tempat istilah itu muncul.

| Istilah | Kepanjangan / arti | Di sistem |
|---|---|---|
| A Check, C Check | Paket maintenance terjadwal berdasarkan interval | M2 Check Type (referensi), Check Pack |
| AD | Airworthiness Directive — perintah wajib dari otoritas | M1 (dokumen), M2 (forecast), M3 (eksekusi) |
| Ad-hoc Task Card | Task card sekali pakai yang dibuat langsung di WO; tidak masuk master (nama usulan) | M3 |
| AFML | Aircraft Flight & Maintenance Log — halaman log penerbangan dan maintenance per sektor | M4 SM1 |
| Alert Level (AL) | Batas rate removal: rata-rata + 2,5 × SD populasi 12 rate bulanan | M4 SM5 |
| Alert Status 1/2/3 | Bulan ketiga / kedua & ketiga / ketiganya melewati alert level | M4 SM5 |
| AMEL | Aircraft Maintenance Engineer Licence | SSG, M3, M4 |
| AMP / MP | Approved Maintenance Program; di sistem disebut **Maintenance Program (MP)** | M2 |
| AOG | Aircraft on Ground — pesawat tidak bisa terbang | M4 2.5 |
| APR / CERT / GOV | Jenis scope kewenangan: approval / sertifikasi / governance | SSG |
| ARC | Airworthiness Release (Return) Certificate | M5, M9, M2 Hard Time |
| ATA | Sistem penomoran chapter pesawat; di Rimbun Air **4 digit chapter-section** (mis. 25-45) | Semua |
| Brought forward | TSN/CSN sektor terakhir halaman AFML non-void sebelumnya | M4 SM1 |
| CASR 121/135 | Peraturan keselamatan penerbangan sipil (operator) | M2 Aircraft Type |
| CDL | Configuration Deviation List | M4 DMI |
| Check Pack | Wadah bebas berisi task untuk dikerjakan bersama (work package) | M2 SM3 |
| CML | Cabin Maintenance Log — catatan defect kabin | M4 7.1 |
| COMA | Sertifikat kompetensi (untuk NDT) | SSG |
| Company Authorization | Kewenangan tanda tangan per orang, per scope, per tipe/PN; kartu RAA-TCI-015 | SSG |
| CRS | Certificate of Release to Service — kini hanya di Workshop | M9 |
| CSN / TSN | Cycles / Time Since New | M1, M2, M3, M4 |
| CSO / TSO | Cycles / Time Since Overhaul | M4 Component Transaction |
| DAAO | Persetujuan otoritas untuk STE tertentu (ditentukan Chief Inspector, usulan) | M2 STE |
| Discrepancy | Entri defect dari AFML yang belum dipilih jalur penyelesaiannya | M4 SM2 |
| DMI | Deferred Maintenance Item — defect yang ditunda dengan batas waktu (tanggal/FH/FC) | M4 SM2 |
| DMI Extension | Perpanjangan DMI, sekali per DMI (dulu "Perpanjangan MEL") | M4 2.3 |
| DoM | Director of Maintenance | Semua |
| Effectivity | Pesawat atau komponen yang terkena task / Check Pack | M2 |
| EO | Engineering Order — perintah teknis internal | M1 |
| EOB | Sebutan pelaku input AFML di dokumen — kepanjangan belum dikonfirmasi | M4 |
| FC / FH | Flight Cycle / Flight Hour | Semua |
| Fleet Status | Status armada dari declaration terakhir (terpisah dari status pesawat M1) | M4 2.6 |
| HIRA | Hazard Identification and Risk Assessment | M2 STE |
| HT / Hard Time / TBO | Batas umur komponen (time between overhaul) yang wajib dilepas/overhaul | M2 Hard Time |
| Issue | Pengeluaran barang dari gudang ke WO | M5 |
| LDND | Last Done Next Due | M2 Report |
| Leg type | Asal part (aircraft atau receiving store) yang dikirim ke Procurement | M4 → M6 |
| LLP | Life Limited Part | M1 |
| MAREP / PIREP | Maintenance Report / Pilot Report — sumber defect | M4 |
| MDDR | Catatan temuan di buku milik MRO pemilik hangar; dideklarasikan di Ad-hoc task card | M3 |
| MEL | Minimum Equipment List, kategori A–D | M4 DMI, RQ |
| MR | Material Request hasil Book (stok cukup) | M3 |
| MSTC | Maintenance Standard, Training & Compliance | SSG |
| MTBUR | Mean Time Between Unscheduled Removal = QPA × jam fleet ÷ removal | M4 SM5 |
| NHA / NLA | Next Higher / Next Lower Assembly | M1 |
| Non-routine Task | Master task untuk masalah berulang, dibuat di M1 (nama usulan) | M1, M2, M3 |
| NRC | Non Routine Card — anak task card untuk temuan yang diselesaikan di WO yang sama | M3 |
| OC/CM | On Condition / Condition Monitoring | M1, M4 Reliability |
| OTA | One Time Authorization — kewenangan sementara 1 atau 7 hari | M1 / SSG (LX-03) |
| Out of Phase | Task yang tidak masuk paket check biasa | M2 |
| Pending Install | Part ber-SN yang sudah di-issue ke WO tetapi belum terpasang | M3, M5 |
| Pending RTS | Part menunggu **Return to Stock** (dilepas atau tidak terpakai) | M3, M4, M5 |
| QPA | Quantity per Aircraft | M4 SM5 |
| QT/FH | Quart per flight hour — konsumsi oli/hydraulic | M4 SM4 |
| RII | Required Inspection Item — wajib diinspeksi orang lain selain pelaksana | M3, SSG |
| Robbed | Part diambil dari pesawat donor dan dipasang di pesawat lain (satu arah) | M4 3.2 |
| RQ / RFQ | Request Part (M4) / Request for Quotation (M6) | M4, M6 |
| RTS | **Return to Service** (dokumen release pesawat per WO) — jangan tertukar dengan *Pending RTS* (return to stock) | M3 |
| Scheduled / Unscheduled | Transaksi komponen dengan / tanpa WO; unscheduled = failure di reliability | M4 |
| Sektor | Satu leg penerbangan; nomor = nomor halaman + urutan (mis. 1001-2) | M4 |
| SoD | Segregation of Duties | SSG |
| STE | Short Term Escalation — perpanjangan batas due, dicatat per kejadian | M2 |
| Swap | Pertukaran part dua arah antar dua pesawat; proses tersendiri | M4 3.6 |
| Technical Record (TR) | Staf yang memverifikasi dan menutup halaman AFML | M4 |
| TFLB | Technical Flight Log Book (halaman AFML di form DMI) | M4 |
| Toggle Fungsi Approval | Saklar per personel yang mengaktifkan seluruh kewenangannya | SSG |
| Waiting TR | Status halaman AFML setelah engineer submit | M4 |
| WCF | Whichever Comes First — due terdekat dari FH, FC, atau kalender | M2 |
| WO | Work Order | M3 |
