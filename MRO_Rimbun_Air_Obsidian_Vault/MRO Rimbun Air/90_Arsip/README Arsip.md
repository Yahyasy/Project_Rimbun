# README Arsip

Folder ini menyimpan **bukti historis**, bukan acuan:

- Ekspor dokumen analisis dari Project Claude (`claude/*.md`), dengan nama file asli. Daftar dan statusnya ada di [[Register Dokumen Sumber#B. Dokumen analisis di Project Claude (bukti historis)]].

- Ekspor rekaman atau transkrip sesi (bila ada).

Aturan:
1. File di sini tidak diedit; bila isinya berubah, buat versi baru dan catat di catatan modul.
2. Catatan modul boleh menautkan ke file arsip sebagai sumber, tetapi kondisi akhir selalu ditulis di catatan modul.
3. Lampiran gambar/PDF baru masuk ke `02_Sumber/Lampiran` (sudah diatur di `.obsidian/app.json`).
